# SafeKey 🔐

**Simple, Secure & Free Password Manager for Everyone**

Save your passwords safely. Generate strong passwords. Backup anytime.
No account needed. No ads. Your data stays on YOUR device.

## ✨ Features

- 🔐 **Save Passwords** - Save site, username and password securely
- 🎲 **Password Generator** - Generate strong passwords (6-32 characters)
    - Uppercase, Lowercase, Numbers, Symbols
- 💾 **Backup & Restore** - Export your passwords as JSON file
    - Share to Google Drive, WhatsApp, Email
    - Restore on new phone in 1 click
- 🔄 **Check for Updates** - Check new version inside the app
- 🌍 **All Platforms** - Android, iOS, Windows, macOS, Linux

1. Download the `.apk` file
2. Tap **Install**
3. If it asks "Install from unknown sources" -> Allow
4. Done! Do NOT uninstall old version when updating, install over it.

---

## 🔄 How to Update?

1. Open SafeKey app
2. Tap **CHECK FOR UPDATES** button
3. If new version is available, tap **DOWNLOAD**
4. Install new version over the old one
5. Your passwords will stay! ✅

> ⚠️ **Important:** Never uninstall the app before updating. Always install new version over the old one. Or use **BACKUP** first!

---

## 💾 Backup / Restore

**Backup:**
1. Tap **BACKUP** button
2. Save file to Google Drive / WhatsApp / Email
3. Keep `safekey-backup-....json` file safe

**Restore:**
1. Install SafeKey on new phone
2. Tap **RESTORE** button
3. Select your backup `.json` file
4. All passwords are back! ✅
